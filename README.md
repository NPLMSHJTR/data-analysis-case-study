# 一个数据分析项目的完整做法

> 以豆瓣 Top250 评论质量分析为样本，记录从「不知道从哪下手」到「每一步都能被复核」的全过程。

这个仓库不是项目成果展示，而是一份**方法案例**。它要回答的问题不是「这个分析得出了什么结论」，
而是「一个人怎么把一件模糊的分析任务，拆成可以一步步执行、可以被别人重新跑一遍的流程」。

代码在这里是证据，不是主角。真正想留下来的是下面六件事：

## 先说结论：这个方法最值钱的地方在哪

如果你只读一段，读这段。

**这个项目里所有「看起来聪明」的结论，都是被数据推翻之后重新做出来的。**

- 第一版情感模型直接拿现成的通用工具，跑出来的相关系数只有 0.0901。这个数字低到可以写一句
  「用户打分和写的字几乎无关」交差。但查下去发现是工具失效——那个模型把 71% 的一星评论判成了正面，
  2 星到 5 星的情感中位数极差只有 0.0075。
- 第一版被低估指数跑出来，前十名全是 9.3 分以上的片子。这不是发现，是把榜单又排了一遍。
- 第一版主类型判定取类型串的第一个词，11 部影片直接从交叉表里凭空消失，图上多出几行任务书里没有的类型。

这三个错误有一个共同点：**代码都没写错，跑起来也不报错，图表还很整齐。**
它们只能靠「盯着结果问一句这合理吗」发现，靠跑测试是跑不出来的。

所以这个案例真正想传的东西，是一套**怀疑自己结果的习惯**，以及把它落成可执行流程的办法。

## 这套流程长什么样

```
  拿到任务
     ↓
① 先划边界 —— 能拿到什么数据、拿不到什么、哪些结论因此不能下
     ↓
② 拆成 14 个可单独运行的阶段 —— 每个阶段有明确输入、输出、失败后果
     ↓
③ 先跑通一条最小链路 —— 哪怕结果难看，先让数字出来
     ↓
④ 逐个阶段怀疑结果 —— 分组看、看分布、和常识对
     ↓
⑤ 发现问题 → 定位是代码错还是判断错 → 改判断
     ↓
⑥ 把「为什么这么改」写进文档，把「改了会影响谁」写进依赖表
```

第 ④ 步是分水岭。大多数人做到第 ③ 步就停了，因为「跑通了」感觉很像是「做完了」。

## 想跑一遍：三条命令

```bash
pip install -r requirements.txt
python main.py                          # 14 个阶段依次执行
python -m pytest tests/ -q              # 111 个测试
```

`main.py` 会打印每个阶段的状态与耗时，并写入 `outputs/run_summary.json`。

**不需要联网**。原始数据已随仓库提供，程序默认复用；只有显式设置 `DOUBAN_FORCE_REFETCH=1` 才会访问豆瓣。

> 环境要求 Python 3.10+，本项目在 3.13.15 上实测通过。
> 装依赖遇到问题的，看 [04 工具与命令](case/04-toolbox.md) 里的镜像源与报错对照。

## 关于数据来源与合法性的声明

这一点必须先说清楚，因为它决定了这个案例能做什么、不能做什么。

| 数据 | 来源 | 处理方式 |
|---|---|---|
| Top250 榜单 | `movie.douban.com/top250` 公开页面 | 正常抓取，每页间隔 2 秒，原始 HTML 全量留档 |
| 影片详情页 | `movie.douban.com/subject/{id}/` | 未登录返回 302 跳转至安全验证页，**未绕过，未采集** |
| 用户短评 | 豆瓣短评页需登录 | **放弃直采**，改用 GitHub 公开数据集 `xiaobing0222/Douban-Movie-Review-Dataset`（2024-04） |
| 市场数据 | 国家电影局、央视网、网易新闻等公开报道 | 12 条，每条标注来源与发布日期 |

违反访问控制去拿数据，技术上做得到，但这个案例不演示这种做法。
代价是覆盖率只有 56.4%（141/250 部有评论），所有涉及评论的结论都因此**不能外推到 Top250 整体**。

这个代价在文档里被反复标注，不是免责声明，而是结论的一部分。

## 这个案例的边界

**能验证的部分**：所有数字都在 `outputs/tables/` 有对应文件，`python main.py` 可重跑，
111 个测试覆盖清洗、分级、一致性、指标与流程完整性。

**不能验证的部分**（已在文档中逐项标注）：

1. 一致性判定的准确率**未被直接验证**——人工标注没有提供独立的一致性真值。这是最大的方法缺口。
2. 情感判定准确率 69.33%，主要误差来自评价对象识别、引用与自述混淆、反讽。
3. Q5 的类型市场热度赋分（0.95、0.85…）是**主观判断**，不是行业统计口径，换个人会给出不同分数。
4. Q2 的时间变化分析因只有单一时间点，标注为**数据不足**，不做任何趋势推断。
5. 版权状态一律标注「需进一步确认」，本案例不掌握任何版权或票房数据。

在文档里区分「数据算出来的」和「我判断的」，比多写一个结论重要。
