# 豆瓣电影 Top250 数据分析课程项目

> 评论质量识别与口碑价值挖掘 —— 人机协同下的双维度评价体系

本项目以豆瓣 Top250 为对象，完成从数据采集、双维度评论质量识别、方法对比实验，
到五个研究问题（Q1—Q5）分析与报告生成的全流程。

**核心主张：星级与文本是两种不同的信号。** 把它们当作同一件事处理，
后续所有口碑结论都会失去意义。

## 二、两个创新点

### 创新一：双维度评论清洗

| | 内容 |
|---|---|
| 原始方法 | 只判断评论有无意义（长度、表情、广告），通过即视为可用 |
| 原始方法的问题 | 识别不出「内容有效但与星级矛盾」的评论，这类样本会污染情感统计 |
| 改进思路 | 增加第二维度判断星级与文本一致性，与内容维度交叉形成处理矩阵 |
| 实验对比（300 条人工集） | F1 0.6682 → **0.7778**；准确率 51.67% → **73.33%** |
| 改进效果 | 成立，但召回率 0.8156 → 0.7821，误杀率 0.1844 → 0.2179 |
| 不足 | 更严格必然误伤；人工标注未提供独立的一致性真值 |

**处理矩阵**（内容有效性 × 星级一致性）：

| 内容 | 一致性 | 处置 |
|---|---|---|
| A 有效 | 一致 | 进入内容分析与情感统计 |
| A 有效 | 轻度不一致 | 进入内容分析，标记不一致 |
| A 有效 | 严重矛盾 | 保留原文，隔离到矛盾样本表，不进一致性统计 |
| B 低信息量 | 任意 | 仅进整体情感统计 |
| C/D/E/X | 任意 | 剔除或待人工判断 |

### 创新二：改进被低估指数

| | 内容 |
|---|---|
| 原始方法 | `U = 0.50·Z(S−R) + 0.30·Z(H) − 0.20·Z(P)` |
| 原始方法的问题 | R 用线性映射到 [−1,1]，9.5 分对应 +0.9，而文本情感均值仅 0.2—0.4，导致高分片 U 恒为负，指数退化为「评分越高越被高估」 |
| 改进 | ① S 与 R 各自做样本内 Z 标准化后再相减；② H 改为平均有用数的对数（无「没用数」）；③ S 只用 A 类且剔除严重矛盾样本 |
| 实验对比 | 改进前前十全是 9.3 分以上（等于再排一次榜）；改进后集中在 8.5—8.7 |
| 改进效果 | 具备区分力；五组权重下秩相关最低 0.9455 |
| 不足 | H 无法区分高赞与高踩；30 条门槛偏低导致名次不稳 |

## 三、数据来源与合法性

| 数据 | 来源 | 状态 |
|---|---|---|
| Top250 榜单（250 条） | `movie.douban.com/top250` 公开页面 | 抓取成功，原始 HTML 全量留档 |
| 影片详情页 | `movie.douban.com/subject/{id}/` | 未登录返回 302 至安全验证页，**未绕过，未采集** |
| 用户短评 | 豆瓣短评页需登录，改用公开数据集 | 见下 |

短评来自 GitHub 公开仓库
[xiaobing0222/Douban-Movie-Review-Dataset](https://github.com/xiaobing0222/Douban-Movie-Review-Dataset)（2024-04），
字段为 `time/uname/comment/star/title/support/sentiment_score`，为抓取时的豆瓣页面原始内容。
本项目只用其原始字段，`sentiment_score`（第三方模型产物）**不采用**，情感分析另行独立完成。

> **覆盖率 56.4%**：148 个影片文件中 141 部能与当前榜单匹配，当前榜单另有 109 部无评论。
> 所有涉及评论的结论均不外推至 Top250 整体。

## 四、五个研究问题的主要结果

| 问题 | 结论 |
|---|---|
| **Q1** | 评分集中在 8.725—9.10（IQR 仅 0.375）；评分人数长尾，取对数后偏度 1.6361 → −0.0021；相关弱（Pearson 0.3148，Spearman 0.1193 不显著） |
| **Q2** | 最大组合「2010—2019 × 剧情」59 部占 23.60%；**因单一时点，占比变化无法计算，标注数据不足** |
| **Q3** | 首位《三块广告牌》U=1.725；前十集中 8.5—8.7；五组权重秩相关 ≥0.9455 |
| **Q4** | 星级与情感弱相关（r=0.2404）；偏差不对称：低星正面 43.75%，高星负面 11.13%，相差 3.9 倍；20 条复核中真实不一致 11 条 |
| **Q5** | 推荐《龙猫》《三块广告牌》《冰川时代》《惊魂记》《2001太空漫游》，覆盖 5 类型 4 年代；版权状态全部标注「需进一步确认」 |

## 五、评论质量分类体系

**第一维度（内容有效性）**，优先级 X → C → D → E → B → A：

| 标签 | 类别 | 判定要点 | 数量 |
|---|---|---|---|
| A | 有效评论 | 对剧情、人物、表演、视听、主题有可辨识评价 | 11,562 |
| B | 低信息量 | 纯表情/数字/填充词，或仅表态 | 130 |
| C | 无关评论 | 广告引流、与影片无关 | 2 |
| D | 疑似异常 | 同片内完全重复或高度相似 | 252 |
| E | 待人工判断 | 过短、语义模糊、反讽黑话 | 624 |
| X | 剔除 | 字段错位、空文本 | 258 |

**不因短而删**：「烂片。」判为 B 类（低信息量），仍保留在整体情感统计中，
但不进入需要信息密度的内容分析。

**第二维度（星级一致性）**：

```
star_norm = (rating − 3) / 2
gap = star_norm − sentiment_score
```

| 档位 | 阈值 | 数量 |
|---|---|---|
| 一致 | \|gap\| < 0.55 | 7,766 |
| 轻度不一致 | 0.55 ≤ \|gap\| < 1.10 | 1,551 |
| 严重矛盾 | \|gap\| ≥ 1.10 | 878 |
| 无法判定 | 置信度 < 0.25 | 1,497 |

**特别处理**：低星（≤2）但含电影要素词的「客观批评」共 292 条，
全部纳入有效评论，单独输出为 `low_star_critique.csv`，用于影片缺点分析。

## 七、关键设计决策

| 决策 | 理由 |
|---|---|
| 不绕过豆瓣登录/验证 | 遵守访问控制，改用公开数据集并披露覆盖率缺口 |
| 「烂片。」保留而非删除 | 长度不是有效性的代理指标 |
| 低星评论不一律当差评 | 拆出「低星客观批评」单独统计（292 条） |
| 情感模型**不用星级训练** | 否则 Q4 构成循环论证，偏差必然趋近零 |
| 词典未命中时用贝叶斯极端值回退 | 准确率 61.67% → 69.33%，未命中率 48% → 12% |
| 严重矛盾样本隔离而非删除 | 遵守「保留原始数据并说明排除范围」 |
| Q2 不做时间变化结论 | 只有单一时间点，任何趋势说法都无据 |
| 推荐引入市场热度维度 | 纯按口碑会推荐「叫好不叫座」的片 |

## 八、已知限制

1. **评论覆盖率 56.4%**：141/250 部有评论，结论不外推至整体
2. **情感准确率 69.33%**：主要误差为评价对象识别、引用与自述混淆、反讽
3. **一致性判定未直接验证**：人工标注无独立一致性真值，这是最大方法缺口
4. **H 被迫替换**：无「没用数」，无法区分高赞与高踩
5. **单一时点**：Q2 时间变化分析标注数据不足
6. **无版权票房数据**：Q5 推荐停在内容层面

## 十、可复现性

- 随机种子固定为 `20261109`
- 所有图表与报告数字由脚本从结果文件读取，无手工填写
- 原始 HTML 快照存于 `data/raw/html_snapshots/`，可离线重建
- 已存在原始数据默认复用；强制重抓设 `DOUBAN_FORCE_REFETCH=1`
- 代码截图由 `src/code_screenshot.py` 从真实源码渲染，非截屏，可复现
- PPT 每页附演讲者备注（`src/ppt_notes.py`），备注里的数字与结果表同源，改数据后重新生成即同步
