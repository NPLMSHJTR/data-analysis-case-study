# 研究方法说明

本文档记录本项目的方法设计、参数取值依据与关键取舍理由。
所有决策在分析开始前确定，分析过程中未依结果反向调整。

---

## 一、总体流程

```
采集 → 文本清洗 → 重复检测 → 内容有效性分级（第一维度）
     → 情感分析 → 星级一致性判定（第二维度）→ 双维度矩阵处置
     → 方法对比实验 → 统计分析 → 指数计算 → 偏差分析 → 推荐 → 报告
```

每层独立成模块，读取上游产物、写出本环节结果。任一环节失败不中断后续可独立完成的环节。

## 二、数据采集

### 2.1 榜单抓取

- 目标：`https://movie.douban.com/top250`，10 页 × 25 条
- 请求头：常规浏览器 UA，不伪造登录态
- 节奏：每页间隔 2 秒
- 重试：单页最多 3 次，指数退避
- 拦截检测：若跳转 `sec.douban.com` 或含「检测到有异常请求」，立即抛异常终止，**不做任何绕过**
- 留档：每页原始 HTML 存 `data/raw/html_snapshots/`

### 2.2 评论数据

短评页未登录返回 302 至 `sec.douban.com`，本项目不绕过，
改用 GitHub 公开数据集（详见 README 第三节）。

载入三步：逐文件读取并匹配片名 → 清理时间字段空白 → 用户名 MD5 哈希脱敏。

## 三、第一维度：内容有效性分级

### 3.1 标签与优先级

六类互斥标签，优先级 `X → C → D → E → B → A`。

优先级依据「排除优先于归类」：字段不可信（X）则不必谈内容；是广告（C）则不必判情绪；
是重复副本（D）则副本本身不单独计价。

### 3.2 判定分档

| 条件 | 判定 | 理由 |
|---|---|---|
| 空文本 | X | 无可分析内容 |
| 命中广告特征 | C | 与影片无关 |
| 纯符号/数字/表情/填充词 | B | 无实义，仍可进情感统计 |
| 长度 < 4 且无评价词 | E | 确实无法判断 |
| 4 ≤ 长度 < 10 且含要素词 | A | 有具体指向 |
| 4 ≤ 长度 < 10 且仅含好恶 | B | 只有简单喜欢/不喜欢 |
| 4 ≤ 长度 < 10 且无要素无判断 | E | 语义模糊 |
| 长度 ≥ 10 | A | 具备可辨识的观影描述 |

**核心原则：不因短而删。**「烂片。」判为 B 类保留，「摄影很棒」判为 A 类。

### 3.3 重复检测

- 完全重复：同片内文本相同，保留最早一条
- 高度相似：字符级 TF-IDF（`char_wb`，2—4 元）+ 余弦相似度，阈值 0.92
- 只在同片内比较，跨片相似不算重复

选择字符级而非分词：模板化文本往往只改个别字词，字符特征更敏感；且无需额外分词词典。

## 四、情感分析

### 4.1 方法选择

采用「领域情感词典 + 否定/程度/转折规则」，理由：

1. 运行环境无法保证下载预训练权重；
2. 规则可追溯到具体词，便于解释成因；
3. **最关键：情感判定完全不使用星级作为输入**。若用星级训练情感模型，
   再检验「星级与文本是否一致」，模型已被教会答案，Q4 失去意义。

### 4.2 词典与规则

| 组件 | 规模/取值 |
|---|---|
| 正面词典 | 约 190 条，权重 0.8—1.8 |
| 负面词典 | 约 170 条，权重 0.8—1.8 |
| 否定词 | 25 条（含「不怎么」「谈不上」等双字形式） |
| 程度副词 | 20 条，系数 1.2—1.8 |
| 转折词 | 8 条 |

**否定处理的三处设计**：

1. 单字「无」「非」不列入否定表——「非常」「无比」中是程度强调，「两小无猜」「无一遗漏」中是成语成分
2. 窗口取情感词前 3 字（初版用 6 字，会把无关的否定字误判为否定）
3. 双重否定检测：窗口内出现 ≥2 个短否定标记时取消反转

### 4.3 评分公式

```
raw   = Σ (weight × polarity × negation_factor × degree_factor × turn_weight)
score = tanh(raw / sqrt(n_hits + 1) / 1.6)
```

- `negation_factor`：被否定时取 −0.9
- `degree_factor`：取窗口内程度副词系数最大值
- `turn_weight`：转折词之后的句子取 1.5
- `tanh` 压缩避免长文本分数爆炸；`sqrt(n_hits+1)` 归一避免命中数直接决定分数

### 4.4 回退机制（改进点）

词典法的主要短板是「未命中任何情感词」——大量靠具体名词与叙述表达态度的评论
（如「吴镇宇一枝独秀」）拿不到分数，导致一致性分析出现大量「无法判定」。

回退规则：未命中时用朴素贝叶斯情感库（snownlp）做**极端值判定**，
只有极性分 >0.80 或 <0.20 才给方向，其余仍判中性；置信度上限压到 0.45，标记为弱证据。

效果（300 条同一人工集，经交叉验证）：

| 方案 | 准确率 | 宏 F1 | 未命中率 |
|---|---|---|---|
| 词典法（无回退） | 61.67% | 0.5764 | 48.0% |
| 朴素贝叶斯（阈值 0.40/0.60） | 64.67% | 0.4661 | — |
| TF-IDF + 逻辑回归（五折交叉） | 68.00% | 0.4060 | — |
| **词典 + 极端值回退** | **69.33%** | **0.6052** | 约 12% |

> 注：TF-IDF + 逻辑回归准确率较高但宏 F1 仅 0.4060，严重偏向多数类，故不采用。
> 回退机制的阈值是在同一验证集上选定的，存在样本内乐观偏差，这一点在报告第十章声明。

## 五、第二维度：星级一致性判定

### 5.1 公式

```
star_norm = (rating − 3) / 2        1星=−1, 3星=0, 5星=+1
gap       = star_norm − sentiment_score
abs_gap   = |gap|
```

### 5.2 四档判定

| 档位 | 阈值 |
|---|---|
| 一致 | abs_gap < 0.55 |
| 轻度不一致 | 0.55 ≤ abs_gap < 1.10 |
| 严重矛盾 | abs_gap ≥ 1.10 |
| 无法判定 | 情感置信度 < 0.25 |

阈值依据：0.40 会把「四星评论里一句『但结尾有点仓促』」判成矛盾；
0.80 会漏掉「五星配通篇差评」。0.55/1.10 在验证集上误判最少。

### 5.3 双维度处理矩阵

| 内容有效性 | 一致性 | disposition | 进入哪类分析 |
|---|---|---|---|
| A | 一致 | `content` | 内容分析 + 情感统计 |
| A | 轻度不一致 | `content` | 内容分析（标记不一致） |
| A | 严重矛盾 | `mismatch_only` | 仅矛盾样本表 |
| A | 无法判定 | `manual` | 待人工判断 |
| B | 任意 | `sentiment` | 仅情感统计 |
| C/D/E/X | 任意 | `excluded` | 完全排除 |

### 5.4 低星客观批评的识别

一星评论若写「叙事混乱、动机缺乏铺垫、节奏拖沓」，是有价值的批评而非脏数据。
本项目用「是否含电影要素词」识别，单独输出为 `low_star_critique.csv`。

实测：二星及以下 A 类评论 576 条，其中 292 条（50.69%）含明确电影要素描述。

## 六、方法对比实验

### 6.1 两套方法

| 步骤 | 方法一 | 方法二 |
|---|---|---|
| 删空评论 | ✓ | ✓ |
| 删完全重复 | ✓ | ✓ |
| 删广告 | ✓ | ✓ |
| 纯噪声识别 | — | ✓ |
| 高度相似检测 | — | ✓ |
| 内容分级 | — | ✓ |
| 一致性判定 | — | ✓ |
| 严重矛盾隔离 | — | ✓ |

两套方法共用同一套文本预处理，只在分级逻辑上不同，保证比较公平。

### 6.2 评价口径

- 真值：人工标注 `human_label == "A"` 视为有效（严格口径）
- 预测：方法判定的「保留/剔除」
- 指标：准确率、精确率、召回率、F1
- 附加：误杀率 = 人工认为有效但被剔除的比例

### 6.3 结果

| 指标 | 方法一 | 方法二 |
|---|---|---|
| 保留比例 | 98.00% | 91.14% |
| 准确率 | 51.67% | **73.33%** |
| 精确率 | 56.59% | **77.35%** |
| 召回率 | **81.56%** | 78.21% |
| F1 | 66.82% | **77.78%** |
| 误杀率 | 18.44% | 21.79% |

**结论**：改进在 F1 上成立（+10.96 个百分点），但召回率下降、误杀率上升。
对研究而言误收代价高于漏收（噪声进情感均值直接污染结果），因此「精确率优先」的取向合理，
但代价必须如实报告。

### 6.4 口径限制

人工标注没有独立的一致性真值，因此：
- 「一致性判定的准确率」**未被直接验证**
- 表中的「误杀率」衡量的是方法的过度排斥程度，**不能等同于一致性识别精度**

这是本项目最需要补上的一环，已在报告第十章列为第一优先改进项。

## 七、被低估指数

### 7.1 公式

```
U = 0.50·Z(S − R) + 0.30·Z(H) − 0.20·Z(P)
```

### 7.2 两处必要调整

**调整一：S 与 R 各自做样本内 Z 标准化**

原始做法把 10 分制线性映射到 [−1,1]（9.5 分 → +0.9），而中文短评的平均情感分
通常只有 0.2—0.4，导致所有高分影片 S−R 恒为负，指数退化为「评分越高越被高估」。

改进后比较发生在「排名」层面：文本情感排名高于评分排名，gap 即为正。
同时保留原始刻度差 `gap_raw` 供直观核对，但不参与计算。

**调整二：H 从「有用率」改为「平均有用数的对数」**

原设有用率需要「没用数」，数据集只提供有用数。按「不得编造」要求改为：

```
H = Z( ln(1 + 该片有效评论的平均有用数) )
```

该替代指标衡量「既有评论被其他用户认可的程度」，与原意一致但粒度更粗：
无法区分高赞与高踩，也无法排除时间累积效应。

**调整三：S 只用 A 类且剔除严重矛盾样本**

避免自相矛盾的评论污染影片的文本情感均值。

### 7.3 权重的研究含义

| 权重 | 维度 | 含义 |
|---:|---|---|
| 0.50 | S − R | 最直接对应「口碑与评分不一致」这一研究兴趣 |
| 0.30 | H | 第二重校验：文本情感可能被极端评论拉高，若这些评论同时高赞则更可信 |
| −0.20 | P | 「被低估」隐含「未被充分发现」，负号给高关注度影片降温 |

### 7.4 稳健性

五组权重下 Spearman 秩相关最低 0.9455，前十重合 6—10 部。
结论：谁进入前十稳健，具体名次不稳。

### 7.5 失真情形

1. 样本量不足：30 条门槛偏低，部分影片情感均值标准误达 0.07
2. 情感模型误差：S 来自准确率 69.33% 的模型，系统误差传导到 U
3. H 的替代性：无法区分高赞与高踩，受发布时间影响
4. 共线性：P 与 H 的 Spearman 相关约 0.35，解释时需避免重复归因

## 八、Q4 偏差分析

### 8.1 不一致程度

```
D = | (rating − 3) / 2 − sentiment_score | / 2      取值 [0, 1]
```

### 8.2 四类重点样本

1. 高星级 + 负面文字（≥4 星，文本判负）
2. 低星级 + 正面文字（≤2 星，文本判正）
3. 三星 + 极端正面（情感分 ≥ 0.60）
4. 三星 + 极端负面（情感分 ≤ −0.60）

候选池每类抽 40/40/15/15 条（同片允许 2 条），最终 20 条由研究者按片名与文本前缀定位。

### 8.3 复核分类

| 类别 | 定义 |
|---|---|
| 真实不一致 | 文本情感方向与星级确实相反 |
| 复杂情感 | 反讽、以贬词表喜爱、正负并存 |
| 模型误判 | 文本真实情感与星级一致，是模型判断错误 |

复核结论由研究者逐条阅读原文后填写，**不由脚本自动生成**。

### 8.4 系统性偏差的判定

不只看 20 条例子，而是计算：
- Pearson / Spearman 相关系数
- 各星级内部情感构成
- 两个方向不一致发生率的对称性

本项目的结论是「存在系统性偏差」，核心证据是两个方向的发生率相差约 3.9 倍。

## 九、Q5 推荐

### 9.1 综合推荐分

```
R = 0.15·Z(评分) + 0.25·Z(U) + 0.15·Z(情感) + 0.08·Z(关注度)
  + 0.07·Z(评论数) + 0.10·Z(年代稀缺性) + 0.20·Z(类型市场热度)
```

评分权重刻意压低至 0.15，避免退化为「Top250 前五名」。
类型市场热度占 0.20，是本项目相对纯口碑方法的改进。

### 9.2 类型市场热度赋分（**主观判断**）

| 类型 | 赋分 | 依据 |
|---|---:|---|
| 动画 | 0.95 | 2025 年为影史动画票房最高年，年度前十动画占四席 |
| 喜剧 | 0.85 | 春节档与暑期档主力，票价下行期更依赖解压类型 |
| 悬疑 | 0.75 | 中小成本易出黑马 |
| 犯罪 | 0.72 | 同上 |
| 剧情 | 0.70 | 大盘主力但同质化竞争激烈 |
| 爱情 | 0.60 | 档期依赖强，非档期上映风险高 |
| 科幻 | 0.55 | 依赖重工业投入，老片特效易显过时 |
| 战争 | 0.50 | 重映需极强时点契合 |
| 纪录片 | 0.45 | 小众但稳定 |
| 动作 | 0.35 | 出现《笑傲江湖：东方不败》重映 15.6 万元的明确反例 |

**重要声明**：上述赋分是分析者基于 12 条公开市场事实的主观判断，
不是行业统计口径。换一个人可能给出不同分数。这一点已在报告表 9-1 与第九章正文中明确标注。

### 9.3 约束

1. 被低估指数 > 0
2. 上映满 8 年
3. 第一轮每类型最多 1 部，不足时第二轮放宽至 2 部
4. 同一十年区间最多 2 部

### 9.4 版权边界

本项目不掌握任何版权、发行、票房数据。所有推荐只说明「内容与口碑层面的重映价值」，
版权状态一律标注「需进一步确认」，不作可行性断言。
